03

Public proof. Private prompts.

Agencies need to disclose that an asset is AI generated. They do not need to hand over the prompt, the seed and the parameters that produced it. That is the creative work.

So the file carries only a hash and a reference. The full record sits in private storage on Backblaze B2. Anyone can check the file. Only you can read the brief behind it.

Struck into the file

  • Content hash
  • Record reference
  • Schema version

Held in private storage

  • The prompt
  • The seed and parameters
  • Model and provider
  • Who signed it off

A pointer names its own record, so a forger could aim it at a record that fits their edited file. The checker binds the record back to the hash struck into the media, and rejects it when they disagree.

04

Nothing ships on the first try.

Generation is a slot machine. Assets are made more than once, checked, and the losing attempts are kept rather than binned. These are the real attempts behind the specimen above, with the reasons they were kept or dropped.

The checks are deterministic on purpose: blank frames, video with no media data, audio cut short of its script. A machine can prove those. It cannot prove taste, so it does not pretend to.
